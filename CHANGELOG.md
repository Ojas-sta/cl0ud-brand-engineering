## [1.0.0] - 2026-11-02

### Added
- Comprehensive machine-readable brand specification in `cl0ud-brand-spec.json` covering all 10 core sections.
- Strict Draft 2020-12 JSON Schema in `schemas/cl0ud-brand-spec.schema.json`.
- Complete visual identity assets in `assets/logos/`:
  - Primary full-color lockup (`cl0ud-primary.svg`).
  - Standalone cloud and zero-node symbol (`cl0ud-icon.svg`).
  - Wordmark (`cl0ud-wordmark.svg`).
  - Monochrome dark and light variants (`cl0ud-monochrome-dark.svg`, `cl0ud-monochrome-light.svg`).
  - Laser-engraving outline vector (`cl0ud-outline.svg`).
  - 32x32 Favicon (`assets/icons/favicon.svg`).
- Standardized SVG attribution badges in `assets/badges/`:
  - `powered-by-cl0ud.svg`
  - `co-engineered-by-ojas.svg`
  - `cl0ud-hybrid-badge.svg`
  - `exhibition-plinth-badge.svg`
- Full brand identity documentation suite in `brand/`:

- Engineering standards, workflows, and monograph specifications in `engineering/`.
- Proposed legal and governance frameworks in `legal/` (with clear non-legal-advice disclaimers).
- In-depth technical portfolio and collaboration model documentation in `documentation/`.
