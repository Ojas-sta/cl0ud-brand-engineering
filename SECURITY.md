# Security Policy

> **System Designation:** Vulnerability Disclosure & Hardware Safety Protocol  
> **Brand Mark:** cl0ud  
> **Administrator:** Ojas Singh (`ojasctc@gmail.com`)

---

## 1. Scope & Commitment

cl0ud takes the security and physical safety of cyber-physical systems, robotics firmware, and web applications seriously. We welcome responsible disclosures of security vulnerabilities or hazardous hardware bugs.

---

## 2. Reporting a Vulnerability

If you discover a security flaw (such as an anti-cheat bypass in `dpsi-exhibition`, an insecure network bridge in firmware, or a power-routing flaw that could cause battery thermal runaway):

1. **Do not create a public GitHub Issue.**
2. Email full technical details, proof-of-concept steps, and environment specifics directly to **Ojas Singh** at:  
   `ojasctc@gmail.com`
3. We will acknowledge receipt within 48 hours and work with you to patch and verify the vulnerability.
